1. Define the agent's tool set as Claude tool-use schemas in a new module under app/: classify_ticket (billing / bug / how-to), search_docs (keyword search over the 40 markdown articles in docs/), draft_reply, and save_reply(ticket_id, text) wrapping the existing database write.
2. Write one system prompt that tells Claude to handle the ticket by taking one action at a time, looking at each tool result before choosing the next action, and to never write out a multi-step plan up front. State that save_reply is the final action and may be called only once.
3. Implement the loop with the Anthropic Python SDK: send the ticket, and while the response has tool_use blocks, execute each tool, append the tool_result to the messages, and call Claude again. Stop when Claude ends its turn or save_reply succeeds.
4. Add guardrails in the loop: a maximum step count (for example 8), a per-call token cap, and a rule that rejects a second save_reply. Log every step (tool name, input, result) so the routing can be audited.
5. Handle failures inside the loop: return tool errors to Claude as is_error tool_results so it can recover, retry transient API errors with backoff, and on hitting the step limit fall back to saving nothing and flagging the ticket for a human.
6. Wire the loop into app/triage.py in place of the current single-call flow, keeping the same inputs and outputs, so POST /triage in app/api.py works unchanged. Read the model name and the step limit from config.py, and keep the API key in an environment variable.
7. Write pytest tests with a stubbed Anthropic client that replays scripted tool-use sequences: a normal billing ticket, a how-to ticket that searches docs, a tool error, a step-limit overrun, and a duplicate save_reply attempt. Assert that save_reply is called exactly once with the right ticket_id.
8. Run the test suite and a small set of realistic sample tickets against the real model with save_reply pointed at a test database. Check that the classifications and replies are sensible, then tune the system prompt and tool descriptions before shipping in the single container.
