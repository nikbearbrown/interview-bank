1. Define the routing contract first: the agent receives a ticket and a fixed set of tools (classify_ticket, search_docs, draft_reply, save_reply, escalate_to_human), each with a strict JSON input schema, so every action the agent can take is a typed Claude tool call.
2. Write a system prompt for the agent in app/agent.py that states its goal (route the ticket to billing, bug, or how-to and get a reply saved), the tool list, and the stop condition (a final save_reply or escalate call), and that tells it to act one step at a time, deciding each next action from the latest observation, with no upfront plan.
3. Implement the loop on the Anthropic SDK Messages API with tool use: send the ticket, execute whichever tool Claude requests, append the tool_result to the message history, and call Claude again until it stops requesting tools.
4. Implement the tools as thin wrappers over existing code: classify_ticket and draft_reply reuse the Claude calls in app/triage.py, search_docs does keyword lookup over the 40 markdown files in docs/, and save_reply wraps the existing database write.
5. Add guardrails around the loop: a hard cap on steps (for example 8), a per-run token budget, validation of tool arguments, a rule that save_reply may run only once per ticket_id (idempotent), and a forced escalate_to_human when the cap is hit or the classification is low-confidence.
6. Wire it into app/api.py as a new route (or a flag on POST /triage) that runs the loop and returns the category, the reply, and the list of steps taken; load the model name and limits from config.py and read the API key from the environment.
7. Write pytest tests in tests/ with a fake Claude client that returns scripted tool calls, covering a normal billing, bug, and how-to path, a loop that hits the step cap, a malformed tool argument, and a duplicate save_reply.
8. Log each step (tool name, arguments, result summary, tokens) for debugging, run the new tests plus the existing suite, then replay a sample of past tickets against the old triage path to compare category accuracy and cost before switching traffic to the new agent in the single container.
