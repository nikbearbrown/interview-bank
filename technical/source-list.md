## 4. Machine-readable datasets (Hugging Face)

| **Dataset**                                                                                                                                  | **Size**               | **License**               | **Notes**                                                                                                                                                                       |
| :------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------- | :------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [newfacade/LeetCodeDataset](https://huggingface.co/datasets/newfacade/LeetCodeDataset)                                                       | 2,869 Python problems  | Apache 2.0                | Has a temporal split: problems released after July 1, 2024 form the test set. Includes difficulty and topic tags, plus a paper (arXiv 2504.14655). The cleanest large set here. |
