# Interview bank (links only)

Private index of technical interview questions and case-interview material. **Pointers only**: no third-party question text, answers, or PDFs are stored here. Every record carries the upstream repository, commit, file path, line locator and URL so the original can be opened at the exact spot.

## Contents

- `technical/questions-links.jsonl`: 34,850 records (topic, subtopic, roles, category, type, question hash, rights class, licences, source locators). Rights classes: {'reference_only': 33184, 'licensed_reuse_candidate': 1666}.
- `technical/source-list.md`, `manifest.json`, `statistics.json`: the 24 source repos/datasets, pinned commits, counts.
- `case-interviews/`: 180 case-reference records (Kellogg, McKinsey, Darden TOC, our own drills), catalog, schema, QA, exclusions; `urls.txt` and `SOURCES.md` list the casebooks to download yourself.
- `scripts/`: extraction scripts and `build_links_index.py` (how the links-only file is made from the full private bank).
